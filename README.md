# Chinmay Goud — Bansuri Portfolio

A React + Vite starter for a cinematic musician portfolio and booking inquiry website.

## Run locally

```bash
npm install
npm run dev
```

## Project notes

- The site introduces Chinmay as a bansuri player who performs with professional bands and live shows.
- Performance and recording areas are explicitly marked placeholders. Replace them with media Chinmay has approved for publication.
- The inquiry form is a front-end demo. It validates the required name and email fields, but does not send or store submissions. Connect a trusted email/form service before launch.
- No awards, testimonials, contact details, venues, or performance credits have been invented.
- Update the About copy with a biography reviewed by Chinmay, and add approved photos, video, audio, Instagram, and genuine testimonials.
